## 2. 相对线框的差异

| 项 | 线框 | 高保真 |
|----|------|--------|
| 视觉完成度 | ASCII / 灰盒示意 `html/` | 色板、字号、48px 主按钮、卡片层级按设计系统落地 |
| 取货码 | 建议 4–6 位 | **固定按 6 位**大号展示（382915） |
| 顾客取消 | 已有「今日 22:00 前」文案 | 弹层居中强化该句 |
| S-ACT-03 | 线框已补 | 高保真弹层展示必填校验态（空原因时确认禁用） |
| 双分区 | 分区 Tab | 预定暖红标识 / 代录棕色虚线新建与卡片底，分区更明显 |
| 加购 | 底栏规格条 | 蒙层 + 规格条；首页保留底部购物车条 |
| 取货时段 | 本批新增 | 确认/代录三档必选；详情 Tag；工作台筛选（F-SLOT-01） |
| 订阅引导 | 本批新增 | 成功帧 + 详情内嵌；无独立设置页（F-SUB-01） |
| `html/` 旧示意 | 线框期 | **仍保留**；评审与对外以 **`hifi/`** 为准 |
| 账号页 | P1 | 未做单独高保真页 |

无业务规则变更超出本批 F-SUB / F-SLOT；**不做开发决策**。字段与群契约一致，详见 `12_f_sub_slot_design.md`。
