## 1. 基准

| 维度 | 以谁为准 |
|------|----------|
| **组件形态**（控件外观、交互范式、默认间距/圆角） | **Vant Weapp** |
| **信息架构、业务规则、文案与流程** | 现有 PRD + 设计稿（`00_*` / 线框 / `hifi/`） |
| **品牌色与关键业务视觉** | 本色板 + 下文「已知冲突」中标 **P0 保留** 项 |

前端：接入 `@vant/weapp`，用主题覆盖主色后替换现有页自定义控件；**不**为对齐而改需求。冲突只提给 PM，不擅自加减。

---

## 2. 主题建议（ConfigProvider / CSS 变量）

覆盖 Vant 默认红 `#ee0a24`，贴近 `01_design_system.md`：

| 用途 | 建议值 | 说明 |
|------|--------|------|
| primary | `#C62828` | 主按钮、价格强调、Tab 选中、关键 Tag |
| success | `#2E7D32` | 已备货、支付/核销成功 |
| warning | `#ED6C02` | 待支付倒计时、注意态 |
| danger | `#D32F2F`（或同系） | 取消/错误；可与 primary 同系 |
| 页面底 | `#FAF7F5` 或接近暖灰 | 可页级背景，不必强改 Vant 组件内白底 |
| 卡片/内容底 | `#FFFFFF` | 与现卡一致 |

实现提示：小程序侧优先 `ConfigProvider` + 对应 CSS 变量（如 `--button-primary-background-color` 等，以当前 Vant Weapp 文档为准）；未覆盖项跟 Vant 默认。

## 3. 页面 → 建议组件映射（简表）

| 场景（页/态） | 建议 Vant 组件 | 备注 |
|---------------|----------------|------|
| 主 CTA / 次按钮 / 危险确认 | **Button** | primary=`#C62828`；次按钮 plain；危险用 danger 或描边+文案 |
| 注册补全、代录表单、搜码、配置项 | **Cell** + **Field** | 店家搜码字号 ≥16 |
| 订单列表 Tab、工作台预定/代录分区 | **Tabs** / **Tab** | 双分区视觉分隔见冲突 P0 |
| 订单状态、上下架等 | **Tag** | 色映射见设计系统状态表 |
| 取消确认、备货/核销确认、代取消 | **Dialog**；多选项用 **ActionSheet** | 原因必填等规则仍按 PRD |
| 商品上下架 | **Switch** | A-SKU-01 |
| 加购数量、代录数量 | **Stepper** | 规格条内 |
| 空列表/无订单 | **Empty** | 文案「暂无订单」等 |
| 页顶导航 | **NavBar** | 与小程序原生导航二选一，避免双顶栏 |
| 首页购物车条 / 待下单底栏 | **SubmitBar** | 可配左侧合计+右侧下单 |
| 列表行（商品、订单卡） | **Cell** / 卡片自定义 + 内嵌 Button/Tag | 复杂卡可自定义块，控件仍用 Vant |
| 取货码大号 | **自定义块** | 见冲突 P0；非 Vant 现成组件 |
| 加购底部规格条 | 自定义半屏 + Stepper/Button；或 Popup | 信息结构按 hifi，控件用 Vant |

顾客关键：C-AUTH / C-HOME / C-CART·下单 / C-PAY / C-LIST·DETAIL / C-ME。  
店家：S-WORK 双区、S-PROXY、S-ORDER、搜码与各确认弹层。  
超管：A-MGMT、A-SKU、A-CFG（Switch/Field/Button）。

## 4. 已知冲突（上报 PM）

| 优先级 | 项 | 建议 | PM |
|--------|-----|------|-----|
| **P0 保留** | 取货码 **40–48px** 大号展示 | Vant 无现成；**自定义块 OK**，勿缩小成普通标题 | 保留 |
| **P0 保留** | 工作台 **预定 / 代录双分区** 视觉分隔 | Tabs + 分区底/边区分；信息架构不变 | 保留 |
| **P1** | 主按钮高 **48px** vs Vant 默认（常约 44） | 可用主题加高，或先接受 Vant 默认 | **待 PM 若卡眼再定** |
| **P1** | 代录区虚线「新建」等强定制样式 | **优先** Button `plain` / `hairline`，弱化定制 | 优先收敛 |

其余圆角、字重以 Vant 为准；品牌色已由主题覆盖。新冲突同样只报 PM，不自行改需求。
