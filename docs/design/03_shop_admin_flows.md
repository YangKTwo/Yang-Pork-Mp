# 店家端 + 超管端线框说明

依据：需求 v1.1 + v1.2；同端入口、管理按角色显隐（PM 已拍板）。  
阅读顺序：先店家工作台与代录，再超管「管理」。

---

## 一、店家端

### 角色与 Tab

```
店家：  工作台 | 我的
超管：  工作台 | 管理 | 我的
```

工作台内 **双分区**（强分隔，不可混为无标签长列表）：

1. **预定订单** — 顾客自助单  
2. **自定义录入** — 电话等旁路代录单

### S-ACT-03 代取消（店家 / 超管）

适用：**待备货、已备货**（未取货）的预定单与代录单；**不受**顾客自助取消 22:00 窗口限制。  
终态订单（已取货 / 已取消 / 已关闭）不展示入口。

```
┌─────────────────────────────┐
│ 取消订单（店家代取消）       │
│ 不受顾客 22:00 自助取消限制。│
│ 取消后不可恢复；已付定金将   │
│ 原路退回。                   │
│                             │
│ 取消原因 *（必填）           │
│ ┌─────────────────────────┐ │
│ │ 例：客户电话改约 / 缺货 │ │
│ └─────────────────────────┘ │
│ 短文本，建议 ≤50 字          │
│                             │
│ [ 再想想 ]    [ 确认取消 ]   │
│                 （主按钮警示）│
└─────────────────────────────┘
```

交互要点：
- 原因空不可点「确认取消」
- 成功 → 订单「已取消」；有线上定金则提示「定金原路退回处理中/已退」
- 超管打开同一订单详情时复用本交互（同端）
