## 3. 字段与契约对齐（设计只定文案/态/布局；实现以契约为准）

### 3.1 F-SLOT-01 取货时段

| 项 | 契约口径 |
|----|----------|
| 字段名 | `pickupSlot` |
| 枚举 | `MORNING` \| `NOON` \| `EVENING` |
| 配置源 | `config.pickupSlots[]`：`{ code, label, hint }` |
| 容量 | **无**容量限制（不展示余量/满档） |
| 店家筛选 | 列表查询带 `?pickupSlot=`（空或省略 = 全部） |

**展示文案（PM 已拍板 2026-10-30；以 config 下发为准，下表为兜底）**：

| code | label | hint（时段说明） |
|------|-------|------------------|
| `MORNING` | 上午取 | 08:00–11:00 |
| `NOON` | 中午取 | 11:00–14:00 |
| `EVENING` | 下午取 | 14:00–18:00 |

UI 展示建议：`{label} · {hint}`，如「中午取 · 11:00–14:00」。实际文案以 config 下发为准；上表为默认兜底。

### 3.2 F-SUB-01 订阅提醒

| 项 | 契约口径 |
|----|----------|
| 触发时机 | **结账成功后**引导授权（成功帧 / 详情内嵌）；非独立设置页 |
| 主路径 | `POST /orders/{id}/subscribe` |
| 状态字段 | `subscribeStatus`：`NONE` \| `ACCEPTED` \| `SENT` \| `SKIPPED_NO_AUTH` \| `FAILED` |
| 发送时机 | 订单进 **PREPARED（已备货）** 且已有授权才发；**无授权静默**（不弹、不连环打扰） |

设计侧 UI 态映射（不暴露全部后端枚举给顾客）：

| UI 态 | 对应大致状态 | 展示 |
|-------|--------------|------|
| 未开启 | `NONE` / `SKIPPED_NO_AUTH` / `FAILED`（可再试） | 引导文案 + CTA「开启取货提醒」 |
| 已开启 | `ACCEPTED` / `SENT` | 「已开启提醒」静态度（勾选或 Tag），弱化二次打扰 |

## 6. 状态与交互规则

### 6.1 订阅

1. 结账成功进入成功帧时：若 `subscribeStatus` 为未开启类 → 展示引导；已开启类 → 展示「已开启提醒」，CTA 弱化或隐藏。
2. 点「开启取货提醒」→ 系统订阅授权（设计只定入口文案）。
3. 用户同意 → UI 切已开启；后端走 `POST /orders/{id}/subscribe`（实现细节非本批）。
4. 用户拒绝/关闭 → Toast「好的，之后可在订单里再开」；本会话不再连环弹；详情仍可手动再开。
5. 进 PREPARED 发提醒：有授权才发；无授权静默（设计无额外 UI）。

### 6.2 时段

1. **默认不预选**（强制顾客确认）；提交前未选 → 主按钮可点但拦截 Toast，或按钮 `disabled` 至选中（hifi 示意：未选时主按钮 disabled）。
2. 三档单选；与取货日并列展示。
3. 店家筛选互斥；「全部」不传或清空 `pickupSlot`。
4. 无容量、无满档态。

## 7. Vant Weapp 映射建议

| 场景 | 建议组件 | 备注 |
|------|----------|------|
| 开启取货提醒 CTA | **Button** primary | 主色 `#C62828` |
| 先看看订单 | **Button** plain / 次按钮 | — |
| 已开启提醒 | **Tag** success 或 Cell 右侧勾 | 静默、弱打扰 |

| 拒绝 Toast | **Toast** | 短文案 |

| 确认页区块 | **Cell** / **CellGroup** | 取货日与时段同卡或紧邻 |

| 卡片时段 | **Tag** | primary-soft 或默认 |
| 未选校验 | Toast 或 Button disabled | 与现确认页一致 |
