# 顾客端关键页线框说明

依据：需求 v1.1 + v1.2；IA 见 `00_ia_and_pages.md`。  
约定：ASCII / 结构化区块为线框；**无独立商品详情**，加购用覆盖态 C-HOME-02。

---

## 流程序列（主路径）

```
登录/注册 → 商品列表 → 加购条 → 购物车/确认下单
    ├─ 窗外 → 不可提交（Banner + 按钮禁用）
    ├─ 总额 ≤10 → 提交成功 → 待备货（生成取货码）→ 订单详情
    └─ 总额 ＞10 → 待支付（10 分钟）→ 支付成功 → 待备货+取货码
                                      └─ 超时 → 已关闭
订单详情 →（当日 22:00 前）取消 → 退定金 → 已取消
```

## C-ORDER-01 下单确认（含定金公式）

```
┌─────────────────────────────┐
│ ← 确认订单                   │
│                             │
│ 取货日  明天 10月24日（固定） │
│ 取货方式 到店自取             │
│                             │
│ 精瘦肉 ×1 斤        ¥15.00  │
│ 肋排 ×1 条          ¥32.00  │
│ ─────────────────────────── │
│ 订单金额            ¥47.00  │
│ 定金应付            ¥9.40   │  ← ＞10 元示例
│ 定金 = 订单金额 × 20%        │  ← 低干扰 13px 灰字
│ （订单满 10 元收取）          │
│                             │
│ 联系人 张三  138****0000     │
│ 备注（选填）[口味/切法偏好…] │  ← O-REM；两端同一 remark
│                             │
│ [ 提交订单并支付定金 ]       │
└─────────────────────────────┘
```

有备注时详情页信息卡回显「备注」行；无备注不占空态。

**≤10 元示例差异**：

- 定金行改为：`无需定金`  
- 灰字：`本单金额未满 10 元，无需支付定金`  
- 主按钮：`提交订单` → 直接待备货并生成取货码  

**窗外**：主按钮禁用 + 顶部提示。

## C-LIST-01 订单列表 / C-ME-01 我的

- 列表：按状态 Tab 或筛选（全部/待支付/待取货/已完成/已关闭）。  
- 我的：姓名、完整或脱敏手机、退出登录；无复杂设置。

## 修订补丁（2026-10-30 · F-SUB-01 / F-SLOT-01）

- **C-ORDER-01**：确认页增加取货时段三档必选（`pickupSlot`=`MORNING|NOON|EVENING`），默认不预选；文案默认「上午取/中午取/下午取」+ 08–11/11–14/14–18（待 PM 可改）。
- **C-SUCCESS**：支付/提交成功后轻量成功帧 + 订阅引导（开启取货提醒 / 已开启提醒）；**无**独立订阅设置页。
- **C-DETAIL**：信息卡展示所选时段；内嵌订阅未开/已开两态。
- 完整可开发标注与 hifi 清单见 **`12_f_sub_slot_design.md`**、`07_hifi_index.md`。

## 关键规则对照（设计验收）

| 规则 | 线框体现 |
|------|----------|
| 12:00–22:00 外不可下单 | Banner + 提交禁用 |
| ≤10 无定金 → 待备货+码 | 确认页文案 + 成功进详情 |
| ＞10 定金 20%、待支付 10 分钟 | 确认页公式 + 待支付倒计时 |
| 22:00 前可取消退定金 | 详情取消入口 + 确认弹层 |
| 无独立详情页 | 仅 C-HOME-02 覆盖态 |
